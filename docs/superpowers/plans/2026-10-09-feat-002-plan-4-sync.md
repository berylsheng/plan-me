# Plan 4: Events sync to Supabase, offline first (FEAT-002 phase D)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The planner's events live in Supabase per account, work offline (including opening the app offline), sync when the connection returns, update live from other devices, and the events already on the phone can be added to an account once, on request.

**Architecture:** `AuthProvider` remembers the last signed-in user on the phone so the planner opens offline. A `SyncEngine` per signed-in user keeps that user's events and a queue of unsent changes (the outbox) in AsyncStorage, applies every change locally first, sends queued changes in order (creates as INSERT, edits and deletes as UPDATE), re-fetches everything the user can see to reconcile, and listens to Supabase Realtime for live changes. `EventsProvider` connects the engine to React; the planner screen reads and writes through it instead of AsyncStorage.

**Tech Stack:** Expo SDK 54, React 19, `@supabase/supabase-js` 2.117 (PostgREST + Realtime), AsyncStorage, Jest + RNTL 12.9, local Supabase (CLI 2.120) for integration tests.

**Spec:** [2026-10-06-accounts-family-sharing-design.md](../specs/2026-10-06-accounts-family-sharing-design.md) §5, §6, §7, §9 Phase D. Roadmap notes: [2026-10-06-feat-002-roadmap.md](2026-10-06-feat-002-roadmap.md) ("Plan 4" bullets — all folded in here).

## Decisions taken with the user (09/10/2026)

1. **Offline sign-in:** opened offline, the app stays signed in as the last user on the phone and shows their saved events; changes queue and sync later. Only a server-confirmed end of the session (SIGNED_OUT, or no session and no network error) goes back to sign-in.
2. **Events already on the phone (from before accounts):** the first person to sign in is asked once: "Add them to your account?" — **Add** (uploaded as personal events) or **Keep them off my account** (not asked again for that account; the next account to sign in is asked).

## Decision taken in this plan (changes spec §6.3)

**Full re-fetch instead of incremental pull.** The engine re-fetches every event the user can see (paged, 1000 per page) on start, on returning to the foreground, on a fresh session, on Realtime (re)connect, and after a change the server rejected; Realtime handles changes in between. A family planner holds hundreds of events, so this is cheap, and it handles deleted rows, events that stop being shared, lost access and late-committing transactions without a cursor. Task 9 updates the spec.

## Global Constraints

- Read the Expo SDK 54 docs (https://docs.expo.dev/versions/v54.0.0/) before adding a package. **No new packages are needed for this plan.**
- No `any`, no `@ts-ignore` / `@ts-expect-error`. Test code may cast fakes with `as unknown as SupabaseClient`.
- Writes: creates are INSERT; edits and deletes are UPDATE (`deleted_at`). Never upsert, never hard delete. The server owns `updated_at`.
- Event ids and series ids are UUID v4. App `dateKey` `'yyyy-mm-dd'` ↔ column `date`; app `'HH:mm'` / `''` ↔ `'HH:mm:00'` / `null`; app `people` (tags like `AZ`) ↔ `legacy_people`; app `occurrenceId` ↔ `series_id`. Titles are 1–200 characters (empty → `Busy`).
- Every event created in this plan is **personal**. Sharing UI is Plan 5.
- Per-user storage keys: `planme:events:<userId>`, `planme:outbox:<userId>`, `planme:sync:<userId>`; last user: `planme:lastUser`. Legacy: `planMeTasks`, `planMeTasks:claimedBy`, `planMeTasks:declinedBy`.
- Local data is deleted **only** on a user-initiated sign-out, never on a `SIGNED_OUT` event. Never send changes without a session.
- `lib/events/*` must not import AsyncStorage or `react-native-get-random-values` (storage and id generators are passed in), except `lib/events/ids.ts`, which only UI code imports. This keeps them runnable in the Node integration tests.
- New integration tests create test users with the local admin API (service-role key from `npx supabase status`, test code only — never in app code).
- Never log or display `AuthResult.code`. Dates dd/mm/yyyy, NZ time. Commit messages start with `FEAT-002:`.

```ts
import AsyncStorage from '@react-native-async-storage/async-storage';
import type { User } from '@supabase/supabase-js';

/** Enough about a user to open their planner without the server. */
export type KnownUser = { id: string; email: string | null };

const KEY = 'planme:lastUser';

export async function readLastUser(): Promise<KnownUser | null> {
  try {
    const raw = await AsyncStorage.getItem(KEY);
    if (!raw) return null;
    const value: unknown = JSON.parse(raw);
    if (typeof value !== 'object' || value === null || !('id' in value) || typeof value.id !== 'string') return null;
    const email = 'email' in value && typeof value.email === 'string' ? value.email : null;
    return { id: value.id, email };
  } catch {
    return null;
  }
}

export async function writeLastUser(user: User): Promise<void> {
  try {
    await AsyncStorage.setItem(KEY, JSON.stringify({ id: user.id, email: user.email ?? null }));
  } catch {
    // Not fatal: the planner just won't open offline next time.
  }
}

export async function clearLastUser(): Promise<void> {
  try {
    await AsyncStorage.removeItem(KEY);
  } catch {
    // Not fatal.
  }
}
```

- [ ] **Step 5: Replace `context/AuthProvider.tsx`**

```tsx
import type { Session, SupabaseClient, User } from '@supabase/supabase-js';
import React, { createContext, useCallback, useContext, useEffect, useMemo, useState } from 'react';

import { type AuthResult, signOut as signOutRequest } from '@/lib/auth/api';
import { authErrorCode } from '@/lib/auth/errors';
import { clearLastUser, type KnownUser, readLastUser, writeLastUser } from '@/lib/auth/lastUser';

type AuthState = {
  session: Session | null;
  /** Who is signed in on this phone. Kept while offline, even when the session can't be refreshed yet. */
  user: KnownUser | null;
  /** The server couldn't be reached to confirm the session. */
  offline: boolean;
  isLoading: boolean;
};

type AuthValue = AuthState & { client: SupabaseClient; signOut: () => Promise<AuthResult> };

const SIGNED_OUT: AuthState = { session: null, user: null, offline: false, isLoading: false };
const knownUser = (user: User): KnownUser => ({ id: user.id, email: user.email ?? null });
const signedIn = (session: Session): AuthState => ({ session, user: knownUser(session.user), offline: false, isLoading: false });

const AuthContext = createContext<AuthValue | null>(null);

/** Publishes who is signed in. Screens get the Supabase client from here too, so tests can pass a fake. */
export function AuthProvider({ client, children }: { client: SupabaseClient; children: React.ReactNode }) {
  const [state, setState] = useState<AuthState>({ ...SIGNED_OUT, isLoading: true });

  useEffect(() => {
    let active = true;
    let sawSession = false;

    // The last user on this phone, so the planner opens at once, even offline.
    readLastUser().then(last => {
      if (active && last) setState(prev => (prev.isLoading ? { ...prev, user: last, isLoading: false } : prev));
    });

    // The real check. Offline with an expired token, supabase-js retries for ~25 s first.
    client.auth.getSession().then(
      ({ data, error }) => {
        if (!active) return;
        if (data.session) {
          if (!sawSession) {
            sawSession = true;
            void writeLastUser(data.session.user);
            setState(signedIn(data.session));
          }
          return;
        }
        if (sawSession) return;
        if (authErrorCode(error) === 'network') {
          setState(prev => ({ ...prev, offline: true, isLoading: false }));
          return;
        }
        // No session and no network problem: never signed in here, or the server ended it.
        void clearLastUser();
        setState(SIGNED_OUT);
      },
      () => {
        if (active) setState(prev => ({ ...prev, isLoading: false }));
      },
    );

    // Don't call other supabase functions inside this callback (supabase-js can deadlock).
    const {
      data: { subscription },
    } = client.auth.onAuthStateChange((event, session) => {
      if (!active) return;
      if (session) {
        sawSession = true;
        void writeLastUser(session.user);
        setState(signedIn(session));
        return;
      }
      if (event === 'SIGNED_OUT') {
        sawSession = false;
        void clearLastUser();
        setState(SIGNED_OUT);
      }
      // INITIAL_SESSION without a session: getSession decides (it can tell offline from signed out).
    });

    return () => {
      active = false;
      subscription.unsubscribe();
    };
  }, [client]);

  const signOut = useCallback(async (): Promise<AuthResult> => {
    const result = await signOutRequest(client);
    if (result.ok) {
      await clearLastUser();
      setState(SIGNED_OUT);
    }
    return result;
  }, [client]);

  const value = useMemo(() => ({ client, ...state, signOut }), [client, state, signOut]);
  return <AuthContext.Provider value={value}>{children}</AuthContext.Provider>;
}

export function useAuth(): AuthValue {
  const value = useContext(AuthContext);
  if (!value) throw new Error('useAuth must be used inside <AuthProvider>');
  return value;
}
```

```ts
/** RFC 4122 version 4 UUID from 16 random bytes. */
export function uuidFromBytes(bytes: Uint8Array): string {
  const b = Uint8Array.from(bytes);
  b[6] = (b[6] & 0x0f) | 0x40;
  b[8] = (b[8] & 0x3f) | 0x80;

  return `${hex.slice(0, 8)}-${hex.slice(8, 12)}-${hex.slice(12, 16)}-${hex.slice(16, 20)}-${hex.slice(20, 32)}`;
```

```ts
/** What to do about a failed Supabase request: retry later, wait for a fresh session, or give up on it. */
export type Failure = 'network' | 'auth' | 'rejected';

export function classifyFailure(error: { code?: string } | null, status: number): Failure {
  // 401 covers an expired token and requests made without a session: wait, never drop.
  if (status === 401 || error?.code === 'PGRST301' || error?.code === 'PGRST303') return 'auth';
  // supabase-js reports a failed fetch as status 0.
  if (status === 0 || status === 408 || status === 429 || status >= 500) return 'network';
  return 'rejected';
}
```

```ts
import type { SupabaseClient } from '@supabase/supabase-js';

import { classifyFailure } from './failures';
import { type EventRecord, insertPayload, isEventRecord, updatePayload } from './rows';

/** A change waiting to be sent. `attempted` means it may already have reached the server. */
export type OutboxOp =
  | { opId: string; kind: 'insert'; record: EventRecord; attempted?: boolean }
  | { opId: string; kind: 'update'; record: EventRecord; attempted?: boolean }
  | { opId: string; kind: 'delete'; id: string; deletedAt: string; attempted?: boolean };

export const newOpId = (): string => `${Date.now().toString(36)}-${Math.random().toString(36).slice(2, 10)}`;

export const opEventId = (op: OutboxOp): string => (op.kind === 'delete' ? op.id : op.record.id);

export const pendingIds = (outbox: OutboxOp[]): Set<string> => new Set(outbox.map(opEventId));

export function isOutboxOp(v: unknown): v is OutboxOp {
  if (typeof v !== 'object' || v === null) return false;
  const op = v as Record<string, unknown>;
  if (typeof op.opId !== 'string') return false;
  if (op.attempted !== undefined && typeof op.attempted !== 'boolean') return false;
  if (op.kind === 'delete') return typeof op.id === 'string' && typeof op.deletedAt === 'string';
  return (op.kind === 'insert' || op.kind === 'update') && isEventRecord(op.record);
}

/**
 * Add a change, folding it into an earlier queued change to the same event (unless that one
 * is being sent right now). Creates stay creates; a delete of a create the server never saw
 * cancels it.
 */
export function enqueue(outbox: OutboxOp[], op: OutboxOp, inFlight: ReadonlySet<string> = new Set()): OutboxOp[] {
  if (op.kind === 'insert') return [...outbox, op];
  const id = opEventId(op);
  const index = outbox.findIndex(earlier => opEventId(earlier) === id && !inFlight.has(earlier.opId));
  if (index === -1) return [...outbox, op];

  const earlier = outbox[index];
  if (earlier.kind === 'delete') return outbox;
  const next = [...outbox];
  if (op.kind === 'update') {
    next[index] = { ...earlier, record: op.record };
    return next;
  }
  if (earlier.kind === 'insert' && !earlier.attempted) {
    next.splice(index, 1);
    return next;
  }
  next[index] = op;
  return next;
}

export type FlushOutcome = {
  /** opIds that are finished: sent, already applied, or given up on. */
  done: string[];
  /** Why sending stopped early, if it did. The rest stay queued. */
  stoppedBy: 'network' | 'auth' | null;
  /** How many changes the server refused (they are dropped; a re-fetch shows the server's version). */
  rejected: number;
};

const DUPLICATE_KEY = '23505';

async function send(client: SupabaseClient, op: OutboxOp): Promise<{ error: { code?: string } | null; status: number }> {
  const events = client.from('events');
  if (op.kind === 'insert') {
    const { error, status } = await events.insert(insertPayload(op.record));
    return { error, status };
  }
  if (op.kind === 'update') {
    const { error, status } = await events.update(updatePayload(op.record)).eq('id', op.record.id);
    return { error, status };
  }
  const { error, status } = await events.update({ deleted_at: op.deletedAt }).eq('id', op.id);
  return { error, status };
}

/** Send changes in order. Stops at the first network or session problem; drops changes the server refuses. */
export async function flushOutbox(client: SupabaseClient, ops: OutboxOp[]): Promise<FlushOutcome> {
  const done: string[] = [];
  let rejected = 0;
  for (const op of ops) {
    const { error, status } = await send(client, op);
    // An edit or delete that matches no row (gone, or no longer ours to see) succeeds with no error.
    if (error && !(op.kind === 'insert' && error.code === DUPLICATE_KEY)) {
      const failure = classifyFailure(error, status);
      if (failure !== 'rejected') return { done, stoppedBy: failure, rejected };
      rejected += 1;
    }
    done.push(op.opId);
  }
  return { done, stoppedBy: null, rejected };
}
```

```ts
import { isOutboxOp, type OutboxOp } from './outbox';
import { type EventRecord, isEventRecord } from './rows';

/** The three AsyncStorage methods the engine needs (AsyncStorage itself fits). */
export type KeyValueStorage = {
  getItem(key: string): Promise<string | null>;
  setItem(key: string, value: string): Promise<void>;
  removeItem(key: string): Promise<void>;
};

export type UserData = { records: Record<string, EventRecord>; outbox: OutboxOp[]; lastFullSync: string | null };

export const emptyUserData = (): UserData => ({ records: {}, outbox: [], lastFullSync: null });

export const userKeys = (userId: string) => ({
  records: `planme:events:${userId}`,
  outbox: `planme:outbox:${userId}`,
  sync: `planme:sync:${userId}`,
});

const parse = (raw: string | null): unknown => {
  if (!raw) return null;
  try {
    return JSON.parse(raw);
  } catch {
    return null;
  }
};

/** One user's events and queued changes. Damaged entries are skipped, not fatal. */
export async function loadUserData(storage: KeyValueStorage, userId: string): Promise<UserData> {
  const keys = userKeys(userId);
  const [rawRecords, rawOutbox, rawSync] = await Promise.all([
    storage.getItem(keys.records),
    storage.getItem(keys.outbox),
    storage.getItem(keys.sync),
  ]);

  const records: Record<string, EventRecord> = {};
  const parsedRecords = parse(rawRecords);
  if (parsedRecords && typeof parsedRecords === 'object' && !Array.isArray(parsedRecords)) {
    for (const value of Object.values(parsedRecords)) {
      if (isEventRecord(value)) records[value.id] = value;
    }
  }

  const parsedOutbox = parse(rawOutbox);
  const outbox = Array.isArray(parsedOutbox) ? parsedOutbox.filter(isOutboxOp) : [];

  const sync = parse(rawSync);
  const lastFullSync =
    sync && typeof sync === 'object' && 'lastFullSync' in sync && typeof sync.lastFullSync === 'string' ? sync.lastFullSync : null;

  return { records, outbox, lastFullSync };
}

export async function saveUserData(storage: KeyValueStorage, userId: string, data: UserData): Promise<void> {
  const keys = userKeys(userId);
  await Promise.all([
    storage.setItem(keys.records, JSON.stringify(data.records)),
    storage.setItem(keys.outbox, JSON.stringify(data.outbox)),
    storage.setItem(keys.sync, JSON.stringify({ lastFullSync: data.lastFullSync })),
  ]);
}

export async function clearUserData(storage: KeyValueStorage, userId: string): Promise<void> {
  const keys = userKeys(userId);
  await Promise.all([storage.removeItem(keys.records), storage.removeItem(keys.outbox), storage.removeItem(keys.sync)]);
}
```

```ts
import { type EventRecord, type EventRow, isEventRow, recordFromRow } from './rows';

/** After fetching everything visible: the server's rows, except events with changes still queued here. */
export function mergeFullFetch(
  local: Record<string, EventRecord>,
  server: EventRow[],
  pending: Set<string>,
): Record<string, EventRecord> {
  const merged: Record<string, EventRecord> = {};
  for (const row of server) {
    if (!pending.has(row.id)) merged[row.id] = recordFromRow(row);
  }
  for (const id of pending) {
    const mine = local[id];
    if (mine) merged[id] = mine;
  }
  return merged;
}

export type RealtimeChange = {
  eventType: 'INSERT' | 'UPDATE' | 'DELETE';
  new: Record<string, unknown>;
  old: Record<string, unknown>;
};

/** One live change from Supabase Realtime. Events with queued local changes are left alone. */
export function applyRealtimeChange(
  local: Record<string, EventRecord>,
  change: RealtimeChange,
  pending: Set<string>,
): Record<string, EventRecord> {
  const id = change.new.id ?? change.old.id;
  if (typeof id !== 'string' || pending.has(id)) return local;

  if (change.eventType === 'DELETE' || typeof change.new.deleted_at === 'string') {
    if (!(id in local)) return local;
    const next = { ...local };
    delete next[id];
    return next;
  }

  const row: unknown = change.new;
  if (!isEventRow(row)) return local;
  const current = local[id];
  if (current?.updatedAt && Date.parse(row.updated_at) <= Date.parse(current.updatedAt)) return local;
  return { ...local, [id]: recordFromRow(row) };
}
```

```ts
import type { SupabaseClient } from '@supabase/supabase-js';

import { classifyFailure, type Failure } from './failures';
import { type EventRow, isEventRow } from './rows';

export const EVENT_COLUMNS =
  'id, owner_id, family_id, visibility, title, date, start_time, end_time, people, legacy_people, series_id, updated_at, deleted_at';

/** PostgREST returns at most 1000 rows per request by default. */
export const PAGE_SIZE = 1000;

export type PullResult = { ok: true; rows: EventRow[] } | { ok: false; reason: Failure };

/** Every event this user can see that isn't deleted, page by page. */
export async function fetchVisibleEvents(client: SupabaseClient, pageSize = PAGE_SIZE): Promise<PullResult> {
  const rows: EventRow[] = [];
  for (let from = 0; ; from += pageSize) {
    const { data, error, status } = await client
      .from('events')
      .select(EVENT_COLUMNS)
      .is('deleted_at', null)
      .order('id')
      .range(from, from + pageSize - 1);
    if (error) return { ok: false, reason: classifyFailure(error, status) };
    const page: unknown[] = data ?? [];
    for (const value of page) {
      if (isEventRow(value)) rows.push(value);
    }
    if (page.length < pageSize) return { ok: true, rows };
  }
}
```

```ts
import type { RealtimeChannel, RealtimePostgresChangesPayload, SupabaseClient } from '@supabase/supabase-js';

import { applyRealtimeChange, mergeFullFetch } from './merge';
import { enqueue, flushOutbox, newOpId, type OutboxOp, pendingIds } from './outbox';
import { fetchVisibleEvents } from './pull';
import type { EventRecord } from './rows';
import { clearUserData, emptyUserData, type KeyValueStorage, loadUserData, saveUserData, type UserData } from './store';

export type SyncState = 'loading' | 'idle' | 'syncing' | 'offline' | 'needs-sign-in';
export type SyncStatus = { state: SyncState; pending: number; lastSyncedAt: string | null };
export const INITIAL_STATUS: SyncStatus = { state: 'loading', pending: 0, lastSyncedAt: null };

export type SyncEngineOptions = {
  client: SupabaseClient;
  userId: string;
  storage: KeyValueStorage;
  /** False while there is no session (offline sign-in): changes queue but nothing is sent. */
  canSync: boolean;
  onChange: (records: Record<string, EventRecord>, status: SyncStatus) => void;
  realtime?: boolean;
  now?: () => Date;
};

export interface SyncEngineLike {
  start(): Promise<void>;
  stop(): void;
  sync(refresh?: boolean): Promise<void>;
  setCanSync(canSync: boolean): void;
  create(records: EventRecord[]): Promise<void>;
  update(record: EventRecord): Promise<void>;
  remove(ids: string[]): Promise<void>;
  clearLocalData(): Promise<void>;
  readonly pending: number;
}

const RETRY_MIN_MS = 2_000;
const RETRY_MAX_MS = 5 * 60_000;
const REFRESH_AFTER_MS = 60_000;

/** One signed-in user's events: changes apply locally first, then go to Supabase when possible. */
export class SyncEngine implements SyncEngineLike {
  private data: UserData = emptyUserData();
  private state: SyncState = 'loading';
  private canSync: boolean;
  private loaded: Promise<void> = Promise.resolve();
  private stopped = false;
  private cleared = false;
  private running: Promise<void> | null = null;
  private again = false;
  private wantRefresh = false;
  private inFlight = new Set<string>();
  private retryMs = RETRY_MIN_MS;
  private timer: ReturnType<typeof setTimeout> | null = null;
  private channel: RealtimeChannel | null = null;
  private saving: Promise<void> = Promise.resolve();

  constructor(private readonly options: SyncEngineOptions) {
    this.canSync = options.canSync;
  }

  get pending(): number {
    return this.data.outbox.length;
  }

  start(): Promise<void> {
    this.loaded = (async () => {
      this.data = await loadUserData(this.options.storage, this.options.userId);
      if (this.stopped) return;
      this.state = 'idle';
      this.emit();
      if (this.options.realtime !== false) this.subscribe();
    })();
    return this.loaded.then(() => this.sync(true));
  }

  stop(): void {
    this.stopped = true;
    if (this.timer) clearTimeout(this.timer);
    this.timer = null;
    if (this.channel) void this.options.client.removeChannel(this.channel);
    this.channel = null;
  }

  setCanSync(canSync: boolean): void {
    this.canSync = canSync;
    if (canSync) void this.sync(true);
  }

  async create(records: EventRecord[]): Promise<void> {
    await this.loaded;
    if (this.stopped) return;
    for (const record of records) {
      this.data.records = { ...this.data.records, [record.id]: record };
      this.data.outbox = enqueue(this.data.outbox, { opId: newOpId(), kind: 'insert', record }, this.inFlight);
    }
    await this.changed();
  }

  async update(record: EventRecord): Promise<void> {
    await this.loaded;
    if (this.stopped) return;
    this.data.records = { ...this.data.records, [record.id]: record };
    this.data.outbox = enqueue(this.data.outbox, { opId: newOpId(), kind: 'update', record }, this.inFlight);
    await this.changed();
  }

  async remove(ids: string[]): Promise<void> {
    await this.loaded;
    if (this.stopped) return;
    const deletedAt = this.now().toISOString();
    const records = { ...this.data.records };
    for (const id of ids) {
      delete records[id];
      this.data.outbox = enqueue(this.data.outbox, { opId: newOpId(), kind: 'delete', id, deletedAt }, this.inFlight);
    }
    this.data.records = records;
    await this.changed();
  }

  /** Stop and delete this user's events and queued changes from the phone. */
  async clearLocalData(): Promise<void> {
    this.stop();
    this.cleared = true;
    await this.saving;
    await clearUserData(this.options.storage, this.options.userId);
  }

  /** Send queued changes, then (when due or asked) re-fetch. Calls while one runs are folded into it. */
  sync(refresh = false): Promise<void> {
    if (this.stopped || this.state === 'loading') return Promise.resolve();
    this.wantRefresh = this.wantRefresh || refresh;
    if (this.running) {
      this.again = true;
      return this.running;
    }
    const run = async () => {
      do {
        this.again = false;
        const doRefresh = this.wantRefresh;
        this.wantRefresh = false;
        await this.runSync(doRefresh);
      } while (this.again && !this.stopped);
    };
    this.running = run().finally(() => {
      this.running = null;
    });
    return this.running;
  }

  private async runSync(refresh: boolean): Promise<void> {
    if (!this.canSync) {
      this.setState('offline');
      return;
    }
    const { client } = this.options;
    this.setState('syncing');

    if (this.data.outbox.length > 0) {
      // Mark everything as possibly sent before sending: a later delete must then reach the server.
      this.data.outbox = this.data.outbox.map(op => (op.attempted ? op : { ...op, attempted: true }));
      const batch: OutboxOp[] = this.data.outbox;
      for (const op of batch) this.inFlight.add(op.opId);
      await this.persist();
      const outcome = await flushOutbox(client, batch);
      for (const op of batch) this.inFlight.delete(op.opId);
      const done = new Set(outcome.done);
      this.data.outbox = this.data.outbox.filter(op => !done.has(op.opId));
      await this.persist();
      if (this.stopped) return;
      if (outcome.stoppedBy) {
        this.fail(outcome.stoppedBy);
        return;
      }
      // A refused change was dropped: show the server's version instead.
      if (outcome.rejected > 0) refresh = true;
    }

    if (refresh || this.refreshDue()) {
      const pulled = await fetchVisibleEvents(client);
      if (this.stopped) return;
      if (!pulled.ok) {
        this.fail(pulled.reason === 'auth' ? 'auth' : 'network');
        return;
      }
      this.data.records = mergeFullFetch(this.data.records, pulled.rows, pendingIds(this.data.outbox));
      this.data.lastFullSync = this.now().toISOString();
      await this.persist();
    }

    this.retryMs = RETRY_MIN_MS;
    this.setState('idle');
    if (this.data.outbox.length > 0) this.schedule(RETRY_MIN_MS);
  }

  private refreshDue(): boolean {
    const last = this.data.lastFullSync;
    return !last || this.now().getTime() - Date.parse(last) > REFRESH_AFTER_MS;
  }

  private fail(reason: 'network' | 'auth'): void {
    if (reason === 'auth') {
      // Wait for a fresh session: the provider calls setCanSync / sync when one arrives.
      this.setState('needs-sign-in');
      return;
    }
    this.setState('offline');
    this.schedule(this.retryMs);
    this.retryMs = Math.min(this.retryMs * 2, RETRY_MAX_MS);
  }

  private schedule(ms: number): void {
    if (this.stopped) return;
    if (this.timer) clearTimeout(this.timer);
    this.timer = setTimeout(() => {
      this.timer = null;
      void this.sync();
    }, ms);
  }

  private subscribe(): void {
    this.channel = this.options.client
      .channel(`events-${this.options.userId}`)
      .on('postgres_changes', { event: '*', schema: 'public', table: 'events' }, (payload: RealtimePostgresChangesPayload<Record<string, unknown>>) => {
        if (this.stopped) return;
        this.data.records = applyRealtimeChange(
          this.data.records,
          { eventType: payload.eventType, new: payload.new, old: payload.old },
          pendingIds(this.data.outbox),
        );
        void this.persist();
        this.emit();
      })
      .subscribe(status => {
        // (Re)connected: catch up on anything missed while disconnected.
        if (status === 'SUBSCRIBED') void this.sync(true);
      });
  }

  private async changed(): Promise<void> {
    this.emit();
    await this.persist();
    void this.sync();
  }

  private persist(): Promise<void> {
    if (this.cleared) return this.saving;
    const snapshot: UserData = { records: { ...this.data.records }, outbox: [...this.data.outbox], lastFullSync: this.data.lastFullSync };
    this.saving = this.saving
      .then(() => (this.cleared ? undefined : saveUserData(this.options.storage, this.options.userId, snapshot)))
      .catch(() => undefined);
    return this.saving;
  }

  private setState(state: SyncState): void {
    this.state = state;
    this.emit();
  }

  private emit(): void {
    if (this.stopped) return;
    this.options.onChange({ ...this.data.records }, { state: this.state, pending: this.data.outbox.length, lastSyncedAt: this.data.lastFullSync });
  }

  private now(): Date {
    return this.options.now ? this.options.now() : new Date();
  }
}
```

```tsx
import AsyncStorage from '@react-native-async-storage/async-storage';
import React, { createContext, useCallback, useContext, useEffect, useMemo, useRef, useState } from 'react';
import { AppState } from 'react-native';

import type { AuthResult } from '@/lib/auth/api';
import { type EventRecord, newRecord, recordsToItems } from '@/lib/events/rows';
import type { KeyValueStorage } from '@/lib/events/store';
import { INITIAL_STATUS, SyncEngine, type SyncEngineLike, type SyncEngineOptions, type SyncStatus } from '@/lib/events/syncEngine';
import type { ItemsByDate, LocalEvent } from '@/lib/events/types';

import { useAuth } from './AuthProvider';

type EventsValue = {
  items: ItemsByDate;
  records: Record<string, EventRecord>;
  status: SyncStatus;
  addEvents: (events: LocalEvent[]) => void;
  updateEvent: (event: LocalEvent) => void;
  deleteEvents: (ids: string[]) => void;
  /** Sign out, then delete this user's events and queued changes from the phone. */
  signOutAndForget: () => Promise<AuthResult>;
};

const EventsContext = createContext<EventsValue | null>(null);

const defaultCreateEngine = (options: SyncEngineOptions): SyncEngineLike => new SyncEngine(options);

type Props = {
  children: React.ReactNode;
  storage?: KeyValueStorage;
  createEngine?: (options: SyncEngineOptions) => SyncEngineLike;
};

export function EventsProvider({ children, storage = AsyncStorage, createEngine = defaultCreateEngine }: Props) {
  const { client, user, session, signOut } = useAuth();
  const userId = user?.id ?? null;
  const accessToken = session?.access_token ?? null;
  const [records, setRecords] = useState<Record<string, EventRecord>>({});
  const [status, setStatus] = useState<SyncStatus>(INITIAL_STATUS);
  const engineRef = useRef<SyncEngineLike | null>(null);
  const tokenRef = useRef(accessToken);
  tokenRef.current = accessToken;
  const recordsRef = useRef(records);
  recordsRef.current = records;

  // One engine per signed-in user; a different user gets a fresh engine and their own storage.
  useEffect(() => {
    setRecords({});
    setStatus(INITIAL_STATUS);
    if (!userId) return;
    const engine = createEngine({
      client,
      userId,
      storage,
      canSync: tokenRef.current !== null,
      onChange: (next, nextStatus) => {
        setRecords(next);
        setStatus(nextStatus);
      },
    });
    engineRef.current = engine;
    void engine.start();
    return () => {
      engine.stop();
      if (engineRef.current === engine) engineRef.current = null;
    };
  }, [client, userId, storage, createEngine]);

  // A session arrived or was refreshed: changes can go out now.
  useEffect(() => {
    engineRef.current?.setCanSync(accessToken !== null);
  }, [accessToken]);

  // Back in the foreground: catch up.
  useEffect(() => {
    const subscription = AppState.addEventListener('change', state => {
      if (state === 'active') void engineRef.current?.sync(true);
    });
    return () => subscription.remove();
  }, []);

  const addEvents = useCallback(
    (events: LocalEvent[]) => {
      if (!userId) return;
      void engineRef.current?.create(events.map(event => newRecord(event, userId)));
    },
    [userId],
  );

  const updateEvent = useCallback((event: LocalEvent) => {
    const existing = recordsRef.current[event.id];
    if (!existing) return;
    void engineRef.current?.update({
      ...existing,
      dateKey: event.dateKey,
      name: event.name,
      startTime: event.startTime,
      endTime: event.endTime,
      people: event.people,
      occurrenceId: event.occurrenceId,
    });
  }, []);

  const deleteEvents = useCallback((ids: string[]) => {
    if (ids.length > 0) void engineRef.current?.remove(ids);
  }, []);

  const signOutAndForget = useCallback(async () => {
    const engine = engineRef.current;
    const result = await signOut();
    if (result.ok && engine) await engine.clearLocalData();
    return result;
  }, [signOut]);

  const items = useMemo(() => recordsToItems(records), [records]);
  const value = useMemo(
    () => ({ items, records, status, addEvents, updateEvent, deleteEvents, signOutAndForget }),
    [items, records, status, addEvents, updateEvent, deleteEvents, signOutAndForget],
  );
  return <EventsContext.Provider value={value}>{children}</EventsContext.Provider>;
}

export function useEvents(): EventsValue {
  const value = useContext(EventsContext);
  if (!value) throw new Error('useEvents must be used inside <EventsProvider>');
  return value;
}
```

```ts
import type { LocalEvent } from './types';

/** Saving an edited sentence: one event stays the same event (sync sends an edit); several replace it. */
export type EditPlan = { kind: 'update'; event: LocalEvent } | { kind: 'replace'; removeIds: string[]; add: LocalEvent[] };

export function planEdit(editing: LocalEvent, fresh: LocalEvent[]): EditPlan {
  if (fresh.length !== 1) return { kind: 'replace', removeIds: [editing.id], add: fresh };
  const { occurrenceId: _ignored, ...rest } = fresh[0];
  const event: LocalEvent = { ...rest, id: editing.id };
  if (editing.occurrenceId) event.occurrenceId = editing.occurrenceId;
  return { kind: 'update', event };
}
```

```ts
import { migrateStoredItems, type StoredEvent } from './items';
import { type EventRecord, recordsFromLegacy } from './rows';
import type { KeyValueStorage } from './store';
import type { ItemsByDate } from './types';

export const LEGACY_KEYS = {
  items: 'planMeTasks',
  claimedBy: 'planMeTasks:claimedBy',
  declinedBy: 'planMeTasks:declinedBy',
};

const parse = (raw: string | null): unknown => {
  if (!raw) return null;
  try {
    return JSON.parse(raw);
  } catch {
    return null;
  }
};

/** The events saved before accounts existed. A damaged day is skipped, not fatal. */
export async function readLegacyItems(storage: KeyValueStorage): Promise<ItemsByDate> {
  const parsed = parse(await storage.getItem(LEGACY_KEYS.items));
  if (!parsed || typeof parsed !== 'object' || Array.isArray(parsed)) return {};
  const items: ItemsByDate = {};
  for (const [dateKey, day] of Object.entries(parsed)) {
    if (!Array.isArray(day)) continue;
    try {
      const events = day.filter((e): e is StoredEvent => typeof e === 'object' && e !== null);
      Object.assign(items, migrateStoredItems({ [dateKey]: events }));
    } catch {
      // skip this day
    }
  }
  return items;
}

const countOf = (items: ItemsByDate) => Object.values(items).reduce((sum, day) => sum + day.length, 0);

async function declinedBy(storage: KeyValueStorage): Promise<string[]> {
  const parsed = parse(await storage.getItem(LEGACY_KEYS.declinedBy));
  return Array.isArray(parsed) ? parsed.filter((id): id is string => typeof id === 'string') : [];
}

/** Whether to ask this user about the events on the phone. */
export async function legacyOffer(storage: KeyValueStorage, userId: string): Promise<{ count: number } | null> {
  if (await storage.getItem(LEGACY_KEYS.claimedBy)) return null;
  if ((await declinedBy(storage)).includes(userId)) return null;
  const count = countOf(await readLegacyItems(storage));
  return count > 0 ? { count } : null;
}

/** Give the events to this user (once): returns them as new personal events to queue for upload. */
export async function claimLegacy(storage: KeyValueStorage, userId: string, newId: () => string): Promise<EventRecord[]> {
  if (await storage.getItem(LEGACY_KEYS.claimedBy)) return [];
  const items = await readLegacyItems(storage);
  await storage.setItem(LEGACY_KEYS.claimedBy, userId);
  return recordsFromLegacy(items, userId, newId);
}

export async function declineLegacy(storage: KeyValueStorage, userId: string): Promise<void> {
  const ids = await declinedBy(storage);
  if (!ids.includes(userId)) await storage.setItem(LEGACY_KEYS.declinedBy, JSON.stringify([...ids, userId]));
}

/** After the claimed events have synced: delete the old copy. */
export async function finishLegacyClaim(storage: KeyValueStorage, userId: string): Promise<void> {
  if ((await storage.getItem(LEGACY_KEYS.claimedBy)) === userId) await storage.removeItem(LEGACY_KEYS.items);
}

/** The claimer signed out before the upload finished: offer the old copy again. */
export async function releaseLegacyClaim(storage: KeyValueStorage, userId: string): Promise<void> {
  if ((await storage.getItem(LEGACY_KEYS.claimedBy)) === userId && (await storage.getItem(LEGACY_KEYS.items))) {
    await storage.removeItem(LEGACY_KEYS.claimedBy);
  }
}
```
